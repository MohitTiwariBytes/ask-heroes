This project is a remake of Ask Heroes by **Sushant Vats**, made for Hack Club's event **Contd**

(https://github.com/sushant-vats/askHeros)

## Introduction

Ask Heroes is basically an AI chat application in which you can chat to AI, but the twist is that you can select which Marvel Superhero you're talking to!

Whichever super hero you choose, AI will answer you in its tone and talking style!

## Features

- **AI Superhero Chat**: Main feature - you can chat with an AI superhero by selecting from the inputbox
- **Save your best chats**: There is a dedicated save page where you can save your chats
- **Authentication**: You can always access all your chats whenever you want just by logging in.
- **Speech to Text**: Tired of typing? you can use your mic to speak whatever you want to the AI.

## Tech Stack

The tech stack i used for this project is NextJS, Hack Club AI, Firebase
